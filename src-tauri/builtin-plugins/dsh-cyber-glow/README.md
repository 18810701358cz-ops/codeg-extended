# DSH Cyber Glow

DeepSeek Harness-inspired cyber neon glow theme for Codeg Extended.
A pure styling plugin that enhances translucent surfaces, card borders, active buttons, and user message bubbles with subtle cyan glow effects in dark mode.

## Features
- Translucent dark surfaces with frosted glass blur
- Neon cyan accents on cards, active buttons, and borders
- Glow highlights for user chat bubbles
