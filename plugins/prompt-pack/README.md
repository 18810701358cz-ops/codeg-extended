# Prompt Pack

A prompt contribution plugin for Codeg Extended.
This plugin contributes a collection of essential developer prompts and shortcuts to Codeg's Quick Messages system via `contributes.quickMessages`.

## Contributed Prompts
- **Code Review**: Review code for potential bugs, performance bottlenecks, and architectural clarity.
- **Write Tests**: Generate comprehensive unit tests covering edge cases and error conditions.
- **Explain Code**: Explain architecture, design patterns, and logic of selected code.
- **Refactor**: Suggest clean refactorings preserving backward compatibility.
